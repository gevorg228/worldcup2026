# Альбом наклеек FIFA World Cup 2026 — трекер

Статический сайт для отметки собранных наклеек Panini «FIFA World Cup 2026».
980 наклеек в 49 наборах (48 стран по 20 + спец-набор FWC из 20: `00`, `FWC1…FWC19`).

## Возможности
- Клик по карточке → наклейка отмечена (зелёная). Поле-число на карточке = сколько штук (повторки на обмен).
- Прогресс набора в % и общий прогресс всех 980 (собрано / осталось / % / на обмен).
- Хранение в браузере (localStorage). Кнопки **Экспорт / Импорт** JSON — бэкап и перенос на другое устройство.
- Работает без сервера и сборки.

## Локальный запуск
Открыть `index.html` напрямую обычно работает, но надёжнее через локальный сервер
(иначе некоторые браузеры ограничивают `file://`):

```bash
# из папки проекта
python -m http.server 8000
# затем открыть http://localhost:8000/
```

## Структура
```
index.html        каркас, подключает css и js
.nojekyll         отключает Jekyll на GitHub Pages
css/style.css     стили
js/data.js        каталог 49 наборов / 980 наклеек (коды как в альбоме)
js/store.js       localStorage + экспорт/импорт
js/progress.js    подсчёт прогресса
js/render.js      рендер главной и страниц наборов
js/app.js         hash-роутинг и обработка кликов
```

## Деплой на GitHub Pages
```bash
git init && git add . && git commit -m "WC2026 sticker tracker"
git branch -M main
git remote add origin https://github.com/gevorg228/worldcup2026.git
git push -u origin main
```
Затем: **Settings → Pages → Source: Deploy from a branch → Branch `main`, папка `/ (root)`**.
Сайт будет на `https://gevorg228.github.io/worldcup2026/`.

## Заметки
- Коды наклеек хранятся буквально: Шотландия — `SC01…SC09`, затем `SC10…SC20`; FWC — `00`, `FWC1…FWC19`.
- Подписи FWC (`Official Ball`, `Canada` и т.д.) и нераспознанные слоты можно дополнить/переименовать в `js/data.js`.
- Бэкап-файл содержит только счётчики (код → число), поэтому импорт остаётся совместимым при будущих правках каталога.
